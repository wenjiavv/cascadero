# 卡斯卡德罗 — 规则摘要与对局手册

Reiner Knizia《Cascadero》的非官方爱好者实现。通过工具调用下棋；没有暗信息，开局之后也没有运气成分。

## 规则摘要

- 2–4 人。每人 30 枚使者、一种颜色（蓝 / 黄 / 橙 / 粉），五条成功轨（蓝、黄、橙、粉、白）上各有一个方块，都从 0 起。
- **一个回合 = 在一个空格放一枚使者。** 城镇也占一个六边格，但不能放使者。
- **城镇计分。** 新放的使者必须属于一个「群」（两枚及以上边相连的己方使者）。新使者相邻的每座城镇，只要这个群里
  没有别的使者已经挨着它，就推进该城镇颜色的方块：
  - 这次落子之前没有任何玩家的使者挨着这座城：1 格；
  - 已经有人挨着：2 格；
  - 城镇上有使者棋（传令官）：再 +1 格。
- **孤子不计分**——除非同时花一枚印章（`use_seal`），那样它按同样的格数规则给相邻的每座城镇计分。
- **同一个群里已经有别的使者挨着的城镇，这个群不能再计分。** 所以孤子挨过的城镇，它长成群以后也计不到（那枚孤子
  还在那儿）；一个群只要一直挨着某座城，就不会对它计第二次。但你的**另一个群**仍然可以对它计分。（使者只在「印章
  已被拿走」那种少见情况下才会移动；若挨着某城的最后一枚使者移走了，这个群以后可以再对它计分。）
- **成功轨**（具体格子见 `get_rules` 的 `tracks`）：得分格（先到的方块拿大数）、连锁格（任选一个方块推 1 格）、
  额外回合格、印章格和两道禁行格。
  - 得分 / 连锁 / 额外回合：经过或停留都触发。
  - 印章格只有**恰好停在上面**才生效：印章还在就拿走；已被拿走则可把自己的一枚使者移到相邻空格。
  - 禁行格（5 和 11）不能停留；本该停在禁行格的推进会停在它下面一格。所以停在 4 或 10 的方块，1 格的推进一律
    无效，必须一次推 2 格以上才能跳过去。
- **成就。** 六个独占成就，先达成者 +3 分：a1 五个方块都 ≥4；a2 手持 3 枚印章；a3 三个方块 ≥10；a4 一个群连接
  全部 5 色城镇；a5 一个方块到 15；a6 一个群连接 3 座同色城镇。同色对：一个群连接 2 座同色城镇 +2 分，每人每色
  一次；五色全部完成再 +10 分。
- **仅背面版图：** 农夫格上有明置板块（+2 分、+3 分、任推一个方块 1 格、额外回合、移动使者棋）。要先在相邻格有
  自己的使者才解锁；把使者放上去（或移上去）立即触发。
- **结束。** 一次落子连同它触发的连锁推进、成就、额外回合全部结算完之后，只要有人 ≥50 分就结束（所以跨过 50 分的那一手
  仍会把连锁决策问完，这些连锁仍可能把你的己色方块推到顶）。另外轮到某人时他已没有使者，也结束。
- **胜负。只有己色方块到达 15 的玩家才有资格获胜。** 有资格者中分高者胜（同分：首轮行动靠后者胜）。无人有资格
  则分高者获得「小胜」。

## 工具怎么用

1. `new_game` → 返回局面和第一个决策。
2. 提示「放使者」时：先 `list_moves`（也可试 `filter="setup"`、`near="<城镇>"`），需要时 `inspect` 某座城或某格，
   然后 `place_envoy`。
3. 一次落子可能中途停下来问你：`choose_track`（连锁 / 农夫推进）、`move_envoy`（停在印章已被拿走的印章格）、
   `move_herald`（农夫板块）。都可以 `skip=true` 放弃。
4. 每个动作的返回里都带「对手做了什么」和「下一个决策」，一般不必再调 `get_state`；想看全图时用
   `include_map=true`。
5. `engine_advice` 问内置电脑怎么走；`undo` 撤回自己上一手。
6. 终局后用 `save_postgame_notes` 记下教训，下次手册里会带上。

坐标写作 `"列,行"`。关键时刻不要靠字符地图目测相邻——`inspect` 和 `list_moves` 给的是精确邻接和精确结果。

## 怎么下好

1. **先保资格。** 己色方块没到 15，拿 50 分也输给任何有资格的对手。数清己色还差几格、从哪几座城来。己色城不多：
   尽量在能拿 2 格或 3 格（别人已访问过、或有使者棋）时去，别只拿 1 格。
2. **敬畏禁行格。** 除非马上有 2 格以上的己色计分，别让己色方块停在 4 或 10。连锁和农夫推进都只有 1 格，跳不过去。
3. **别「烧城」。** 用孤子贴着你想要的城镇起手，等于让这个群永远放弃这座城。先落在隔一格的位置，第二枚再贴城。
4. **做第二个访客。** 一座城第一次计分 1 格，之后都是 2 格。让对手去开城，你跟进；如果对手下一手就能在同一座城
   拿 2 格（有使者棋是 3 格），就别替他开。
5. **找同时挨着两三座未计分城镇的格子**——一枚使者，多次推进。
6. **算好步数去踩印章。** 印章只在恰好停在印章格时得到。印章能让任意孤子直接计分，攒到 3 枚还有成就；先拿走也等于
   不给对手。
7. **多个小群比一条长蛇更能刷轨道**，因为每个群都能对同一座城再计一次分；而群类成就（a4、a6、同色对、+10）需要
   一个大群。想清楚自己在做哪件事。
8. **盯着终局时钟。** 有人到 50 分的那一手结算完就结束。你已有资格且领先就冲分；对手领先且快拿到资格，就去占他己色城镇旁的
   空格——每座城旁的空格是有限的。
9. **额外回合会滚雪球。** 在大计分格之前、或为抢一个双方都要的格子而拿到的额外回合，比格子上写的更值钱。
